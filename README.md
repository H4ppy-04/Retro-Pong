<h1>Pong</h1>

An 8-bit style incarnation of the retro arcade game Pong.

<h2>About</h2>

This particular rendition of Pong features a player vs player system where each
paddle can be controlled by <kbd>W</kbd> and <kbd>S</kbd> for player A and the
<kbd>Up</kbd> and <kbd>Down</kbd> arrow keys for player B.

The score is kept track of for both players, and the score reset if either
player reaches three points.

There are sound effects that were supplied by <a href="https://opengameart.org">Open Game Art</a> and the font is supplied by <a href="https://kenny.nl/assets/kenney-fonts">kenney.nl</a>.

<h3>Usage</h3>

To run the program, create a virtual environment, install the requirements file
using pip and run main.py using python3. Consult platform and shell-specific
documentation as this process varies.
